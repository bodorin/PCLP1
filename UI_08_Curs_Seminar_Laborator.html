Ce ar trebui să știți deja (din unitatea anterioară)

Recapitulare – începător
  • O expresie este o combinație de operanzi (constante, variabile, apeluri de funcții) și operatori. Orice expresie are o valoare și un tip.
  • Un operator este unar (un operand: -x, !x), binar (doi operanzi: a + b) sau ternar (trei operanzi: doar ?:).
  • Aritmetici: + - * / %. Între doi întregi, / este împărțire întreagă (7/2 == 3), iar % este restul (7%2 == 1).
  • Operatori relaționali și logici: < <= > >= == !=, && || !. În C, o condiție este adevărată dacă e nenulă și falsă dacă e 0.
  • Atribuirea = și atribuirea compusă += -= *= /= %=: x += 3 înseamnă x = x + 3. O atribuire este ea însăși o expresie, cu valoarea care a fost memorată.
Recapitulare – mediu
  • lvalue = o expresie care desemnează o locație de memorie (o variabilă) și poate apărea în stânga lui =. rvalue = o simplă valoare (5, a+b). Distincția este esențială pentru ++/--.
  • Efect secundar = o modificare a stării programului (de exemplu a valorii unei variabile) produsă în timpul evaluării unei expresii. a = 3 și a++ au efecte secundare; a + 3 nu are.
  • Conversii implicite: în 2 + 3.5 operandul int este convertit automat la double.

Operatorul virgulă ,

Mai multe expresii acolo unde e permisă una singură
Începător

Uneori, într-un anumit punct al programului, trebuie realizat un calcul complex, exprimat prin mai multe expresii, deși limbajul permite acolo una singură (de exemplu în antetul unei bucle for). Operatorul virgulă unește mai multe expresii într-una singură.

exp1 , exp2 , ... , expn
RegulaExpresiile se evaluează pe rând, de la stânga la dreapta. Întreaga expresie (cele n expresii separate prin virgulă) are valoarea și tipul ultimei expresii, expn. Valorile celorlalte expresii se pierd; ele contează doar prin efectele lor secundare (de obicei atribuiri).

Exemplu rezolvat (din curs)

float c;
// expresia:
c = a = b + 3 , a = c + 2 , b = b + 3

Mediu

1. Separator sau operator?

Virgula este operator numai acolo unde se așteaptă o expresie. În locurile următoare este doar separator:

  • în declarații: int a = 1, b = 2;
  • între argumentele unei funcții: f(a, b) apelează f cu două argumente. f((a, b)) o apelează cu un singur argument, valoarea lui b;
  • în listele de inițializare: int v[3] = {1, 2, 3};
  • între parametrii din definiția unei funcții.

2. Are cea mai mică prioritate dintre toți operatorii

Chiar și atribuirea leagă mai strâns decât virgula. De aici o capcană clasică:

prioritate_virgula.cppC++
int x, y;
x = 1, 2;      // se interpretează (x = 1), 2;   → x == 1 ; valoarea 2 e calculată și pierdută
y = (1, 2);    // parantezele forțează întâi virgula → y == 2

GCC avertizează: „right operand of comma operator has no effect [-Wunused-value]”. Compilați întotdeauna cu avertismentele activate (-Wall -Wextra).

3. Utilizări legitime tipice

  • mai multe inițializări/actualizări în antetul unui for;
  • o condiție de while care trebuie întâi să citească o valoare: while (cin >> x, x != 0) { ... }. Bucla se oprește la citirea lui 0. O formă modernă mai clară este while (cin >> x && x != 0);
  • în macrodefiniții, pentru a executa mai multe acțiuni ca o singură expresie.
StilÎn afara antetului lui for, operatorul virgulă face de obicei codul mai greu de citit. Preferați instrucțiuni separate: a = 1; b = 2;, nu a = 1, b = 2;.
Avansat
  • Secvențiere. Operatorul virgulă este unul dintre puținii operatori care garantează o ordine: operandul stâng este evaluat complet și toate efectele lui secundare sunt încheiate înainte de evaluarea operandului drept. În C acesta se numește punct de secvență (sequence point); în C++11 și ulterior, operandul stâng este secvențiat înaintea celui drept. Astfel i++, i++ este bine definit, dar i++ + i++ nu este (vezi §6).
  • Valoarea din stânga se pierde. Formal este o expresie cu valoare ignorată (discarded-value expression); compilatorul o poate chiar converti la void. Scrierea (void)expr, alta documentează această intenție.
  • C și C++ (categoria valorii). În C rezultatul operatorului virgulă nu este niciodată lvalue. În C++ rezultatul este lvalue dacă operandul drept este lvalue, deci (a, b) = 5; este valid în C++ (atribuie 5 lui b), dar invalid în C.
  • Supraîncărcare. În C++ virgula poate fi supraîncărcată pentru tipuri clasă (operator,). Practica este puternic descurajată: înainte de C++17, o virgulă supraîncărcată nu păstra garanția de evaluare stânga → dreapta. Unele biblioteci (Boost.Assign, inițializatorii << din Eigen) o folosesc pentru sintaxe speciale.
  • În expresii constante. O expresie cu virgulă nu poate apărea fără paranteze în anumite contexte, de exemplu în dimensiunea unui tablou în C sau ca argument de șablon în C++: arr[1, 2] este depreciat în C++20 și are alt sens în C++23 (indice multidimensional).

Operatorul condițional ?:

Singurul operator ternar: alege una din două valori
Începător

Se folosește atunci când există două variante de obținere a rezultatului, în funcție de îndeplinirea unei condiții.

exp1 ? exp2 : exp3
  1. Se determină valoarea expresiei exp1 (condiția).
  2. Dacă aceasta este diferită de 0 (adevărată), se evaluează exp2, iar exp3 este ignorată.
  3. Altfel (0, falsă), se evaluează exp3, iar exp2 este ignorată.

În ansamblu, expresia are valoarea (și tipul) aceleia dintre exp2 / exp3 care a fost aleasă.

Figura 2.1 – Doar una dintre cele două ramuri este evaluată.

Exemple din curs

maxim.cppC++
int a, b, max;
max = (a > b) ? a : b;      // max primește ca valoare maximul dintre a și b
valoare_absoluta.cpp (C++ modern)C++
#include <iostream>
using namespace std;

int main() {                 // citește a de tip float și tipărește |a|
    float a;
    cout << "a=";  cin >> a;
    cout << (a >= 0 ? a : -a) << endl;
    return 0;
}

Aceeași logică scrisă cu if: if (a >= 0) cout << a; else cout << -a;. Operatorul condițional este mai scurt și, fiind o expresie, poate fi folosit în interiorul altor expresii: într-o atribuire, ca argument de funcție sau într-o instrucțiune de afișare.

Mediu

1. Paranteze în instrucțiunile de afișare

?: are prioritate foarte mică: mai mică decât <<, decât operatorii aritmetici și decât cei relaționali. În cout << el trebuie pus între paranteze:

paranteze.cppC++
cout << (x == y ? " este " : " nu este ");   // corect
cout <<  x == y ? " este " : " nu este ";    // EROARE: se interpretează ((cout << x) == y) ? ... : ...

2. Se evaluează o singură ramură, deci vă poate proteja

impartire_sigura.cppC++
double r = (b != 0) ? (double)a / b : 0.0;   // nu se încearcă niciodată împărțirea la zero
int    v = (n > 0) ? arr[n - 1] : -1;         // niciun acces în afara tabloului când n == 0

3. Imbricare și asociativitate de la dreapta

?: se grupează de la dreapta la stânga, așa că un lanț se citește ca dacă / altfel dacă / altfel:

semn_si_calificativ.cppC++
int semn = (x > 0) ? 1 : (x < 0) ? -1 : 0;
// se interpretează  (x > 0) ? 1 : ((x < 0) ? -1 : 0)

char calif = (p >= 90) ? 'A' :
             (p >= 80) ? 'B' :
             (p >= 70) ? 'C' : 'F';

int max3 = (a > b) ? (a > c ? a : c) : (b > c ? b : c);   // maximul a trei numere

5. ?: față de if: expresie față de instrucțiune

if este o instrucțiune: alege ce se execută. ?: este o expresie: alege ce valoare se produce. Folosiți ?: când ambele ramuri calculează o valoare de tip compatibil.

Avansat

1. Tipul unei expresii condiționale

Tipul se stabilește la compilare, înainte ca programul să știe ce ramură se va executa. Dacă exp2 și exp3 sunt aritmetice, se aplică conversiile aritmetice uzuale pentru a obține un tip comun:

tip_conditional.cppC++
bool t = true;
cout << (t ? 1 : 2.5);          // afișează 1, dar tipul este double (sizeof == 8)
cout << (t ? 'A' : 0);          // afișează 65, nu A: tipul comun pentru char și int este int
auto  z = (t ? 7u : -1);        // unsigned int!  dacă t ar fi fals, z ar fi 4294967295

Alte reguli: dacă ambii operanzi sunt pointeri, rezultatul are un tip pointer comun. Dacă o ramură este o expresie throw, tipul este cel al celeilalte ramuri (C++). Pentru tipuri clasă se încearcă conversii între cele două tipuri.

2. Categoria valorii (C și C++)

În C++, dacă exp2 și exp3 sunt amândouă lvalue de același tip, rezultatul este un lvalue și i se poate atribui o valoare:

conditional_lvalue.cppC++
int p = 1, q = 2;
(p > q ? p : q) = 10;   // valid în C++: pune 10 în cel mai mare (q) → p == 1, q == 10
                        // INVALID în C: rezultatul lui ?: nu este niciodată lvalue în C

3. Diferențe de gramatică între C și C++

În C++ al treilea operand este o expresie de atribuire, deci a ? b : c = d se interpretează a ? b : (c = d). În C, ?: are prioritate mai mare decât atribuirea, iar același text este o eroare de compilare: ar însemna (a ? b : c) = d, iar în C acesta nu este lvalue. Puneți paranteze și problema nu mai apare.

4. Secvențiere

După evaluarea lui exp1 există un punct de secvență. Toate efectele lui secundare sunt încheiate înainte să înceapă ramura aleasă. Prin urmare i++ ? i : 0 este bine definit.

5. Observație despre performanță

Compilatoarele moderne transformă adesea un ?: simplu (și un if echivalent) în instrucțiuni mașină fără salt (de ex. cmov pe x86). Alegeți între ?: și if după lizibilitate, nu după viteză. În funcțiile constexpr din C++11, ?: era singura formă de ramificare.

6. Extensia GNU x ?: y

GCC/Clang acceptă x ?: y, adică x ? x : y, cu x evaluat o singură dată. Forma nu este standard. Nu o folosiți în cod portabil sau la examen.

Operatorii de incrementare și decrementare ++ --

Adună sau scad 1, înainte sau după folosirea valorii
Începător

++ incrementează (adună 1) și -- decrementează (scade 1) conținutul unei variabile. Fiecare are două forme:

Figura 3.1 – Cele patru forme.
Regula de bază Prefixat (++a, --a): variabila este incrementată/decrementată înainte ca valoarea reținută de ea să intre în calcul. Expresia produce valoarea nouă.
Postfixat (a++, a--): variabila este incrementată/decrementată după ce valoarea ei a intrat în calcul. Expresia produce valoarea veche.
În ambele cazuri, după instrucțiune variabila s-a modificat cu exact 1.

Un truc de memorare: citiți de la stânga la dreapta. În ++a întâlniți întâi ++, deci întâi incrementați și apoi folosiți a. În a++ întâlniți întâi a, deci întâi îl folosiți și apoi îl incrementați.

Dacă operatorul stă singur într-o instrucțiune, cele două forme au același efect: a++; ≡ ++a; ≡ a = a + 1; ≡ a += 1;

Se pot incrementa doar variabile

++ și -- trebuie să memoreze o valoare nouă, deci se aplică numai variabilelor (mai exact, lvalue-urilor modificabile). Expresiile următoare sunt incorecte și nu se compilează:

++4;   4--;   (5+a)++;   (5+a)--;   ++(10+b);   --(10+b);

Nici o variabilă const nu poate fi incrementată: const int k = 3; k++; este o eroare.

Prioritate și interpretare

  • Forma postfixată a++ are prioritatea cea mai mare (împreună cu () și []). Forma prefixată ++a are aceeași prioritate ca ceilalți operatori unari (-, !, cast, sizeof). Ambele leagă mai strâns decât * și +.
  • -5 * i++ - 12 % 5 se interpretează ((-5) * (i++)) - (12 % 5).
  • Analizorul lexical este „lacom” (maximal munch): a+++b se citește a++ + b, nu a + ++b. a+++++b se citește a++ ++ +b, ceea ce este o eroare. Folosiți spații: a++ + ++b.
  • -a++ înseamnă -(a++): opusul valorii vechi. a este totuși incrementat.

În bucle: i++ sau ++i?

În for (i = 0; i < n; i++) valoarea lui i++ nu este folosită, deci i++ și ++i se comportă la fel și, pentru int, produc cod mașină identic. Pentru iteratorii C++ și alte tipuri clasă preferați ++it: forma postfixată trebuie să creeze o copie a obiectului vechi (vezi nivelul avansat).

Tipuri

++/-- funcționează pe orice tip aritmetic, nu doar pe int. float f = 1.5; f++; dă 2.5. char c = 'a'; c++; dă 'b'. Funcționează și pe pointeri, unde trec la elementul următor sau anterior.

Avansat

1. Efecte secundare și secvențiere: cea mai importantă regulă a unității

Standardul spune când se produce valoarea lui a++ (valoarea veche). Despre incrementare spune doar că va fi făcută înainte de următorul punct de secvență (C), sau că este nesecvențiată față de ceilalți operanzi ai aceluiași operator (C++11). Pentru majoritatea operatorilor binari (+ - * / % < ==…) și ordinea în care se evaluează cei doi operanzi este nespecificată.

Comportament nedefinit (UB – undefined behavior)Dacă o variabilă scalară este modificată de două ori, sau modificată și și citită (altfel decât pentru calculul noii valori) fără un punct de secvență între ele, comportamentul este nedefinit: se poate întâmpla orice, iar compilatoare diferite dau, legitim, rezultate diferite.
comportament_nedefinit.cppC++
i = i++ + 1;       // UB în C și în C++ înainte de C++17
x = ++y * --y;     // UB în toate standardele (y modificat de două ori, nesecvențiat)
x = i + i++;       // UB (i citit și modificat, nesecvențiat)
f(i++, i);         // UB/nespecificat: ordinea evaluării argumentelor nu este definită
a[i] = i++;        // UB înainte de C++17; definit din C++17 (întâi partea dreaptă)

GCC 13 afișează y = 10, x = 100: aplică întâi ambele efecte secundare și apoi înmulțește 10 · 10. O citire strictă de la stânga la dreapta ar da 11 · 10 = 110. Niciun răspuns nu este „corect”, pentru că programul nu are un sens definit. GCC chiar avertizează: „operation on 'y' may be undefined [-Wsequence-point]”. A doua linie afișează 11 12 13 cu C++17 sau mai nou, unde operanzii lui << se evaluează de la stânga la dreapta. Înainte de C++17 rezultatul era nespecificat (unele compilatoare vechi afișau 13 12 11).

Regula de aurÎntr-o singură expresie, nu folosiți nicăieri altundeva o variabilă pe care o incrementați sau decrementați și nu modificați aceeași variabilă de două ori. Împărțiți expresia în mai multe instrucțiuni.

2. Unde există puncte de secvență (garanții de ordine)

  • la sfârșitul fiecărei expresii complete (; al unei instrucțiuni, condiția din if/while, fiecare parte din antetul lui for);
  • după operandul stâng al lui &&, || și al operatorului virgulă;
  • după condiția (primul operand) lui ?:;
  • înainte de intrarea într-o funcție: toate argumentele sunt evaluate complet, dar într-o ordine nespecificată;
  • doar în C++17: în a = b partea dreaptă se evaluează înaintea celei stângi; în a << b, a >> b, a[b] și a.b partea stângă se evaluează înaintea celei drepte.

3. Categoria valorii: C și C++

  • În C, atât ++a cât și a++ produc un rvalue. ++ ++a este o eroare.
  • În C++, ++a produce un lvalue (variabila însăși), deci ++ ++a și (++a) = 7 se compilează (primul este bine definit din C++11). a++ este întotdeauna un prvalue (o copie temporară), deci a++ ++ este o eroare.

4. Tipuri speciale de operanzi

  • bool: b++ pe un bool a fost depreciat și eliminat în C++17. b-- nu a fost permis niciodată.
  • Pointeri: p++ avansează cu sizeof(*p) octeți, adică la elementul următor. *p++ înseamnă *(p++): citește elementul curent și apoi avansează. Este idiomul clasic din C pentru parcurgerea tablourilor: while (*d++ = *s++); copiază un șir.
  • Depășire: INT_MAX + 1 prin ++ este o depășire cu semn, adică UB. Pentru tipurile unsigned valoarea revine la 0, ceea ce este bine definit.

5. Supraîncărcarea în C++ și de ce se preferă ++it

supraincarcare_incrementare.cppC++
struct Contor {
    int v = 0;
    Contor& operator++()    { ++v; return *this; }               // prefixat: fără copie
    Contor  operator++(int) { Contor vechi = *this; ++v; return vechi; } // postfixat: parametru int fictiv, întoarce o COPIE
};

Versiunea postfixată trebuie să construiască și să întoarcă o copie a obiectului vechi. Pentru iteratori mari asta costă timp, dacă optimizatorul nu o elimină. De aici obiceiul din C++ de a scrie ++it în bucle.

Operatorul sizeof (dimensiune)

Câți octeți ocupă un tip sau o expresie?
Începător

sizeof dă dimensiunea în octeți a unui tip de date sau a rezultatului unei expresii. Deși este cuvânt cheie, este un operator, nu o funcție.

sizeof (tip)      sizeof (expresie)      sizeof expresie

Pentru un tip parantezele sunt obligatorii. Pentru o expresie sunt opționale: sizeof x este valid.

Mediu

1. Tipul rezultatului: size_t

sizeof întoarce o valoare de tip size_t, un tip întreg fără semn definit în <cstddef>/<stddef.h>. Cu printf folosiți formatul %zu: printf("%zu\n", sizeof(double));. Amestecarea lui cu int-uri negative în comparații este periculoasă (vezi §5, nivelul avansat).

2. Dimensiunea unei expresii este dimensiunea tipului ei

sizeof(3 + 2*4) nu depinde de valoarea 11, ci de tipul expresiei (int). La fel, sizeof(3.0f + 1) = 4 (float), sizeof(1 + 2.0) = 8 (double), sizeof('a' + 'b') = 4 (ambele char sunt promovate la int).

3. Numărul de elemente al unui tablou

int v[10];

size_t n     = sizeof(v) / sizeof(v[0]); // 10 elemente – merge pentru orice tip de element

Metoda funcționează doar acolo unde tabloul însuși este vizibil. Într-o funcție care primește tabloul ca parametru, parametrul este un pointer, deci sizeof dă dimensiunea unui pointer (vezi nivelul avansat). În C++ modern folosiți std::size(v) (C++17) sau std::array.

4. Constantele caracter: C și C++

În C, 'a' are tipul int, deci sizeof('a') este 4. În C++, 'a' are tipul char, deci rezultatul este 1. O întrebare clasică de examen.

5. De ce să folosim sizeof?

  • Portabilitate: nu scrieți niciodată direct 2 sau 4. Scrieți sizeof(int).
  • Memorie dinamică: malloc(n * sizeof(double)) (C). Și mai bine: malloc(n * sizeof *p), care rămâne corect dacă se schimbă tipul lui p.
  • Fișiere binare și zone tampon: fwrite(&x, sizeof x, 1, f).
Avansat

1. Operandul nu este evaluat

sizeof se calculează la compilare, doar din tip. Operandul său este un operand neevaluat, așa că efectele secundare din interior nu se produc niciodată:

sizeof_neevaluat.cppC++
int i = 3;
size_t s = sizeof(i++);   // s == 4, dar i este ÎNCĂ 3 – i++ nu se execută niciodată
size_t t = sizeof(f());   // f NU este apelată; se folosește doar tipul întors

Excepție (doar C99): pentru un tablou de lungime variabilă int v[n];, sizeof v se calculează la execuție. Tablourile de lungime variabilă (VLA) nu fac parte din C++ standard.

2. Transformarea tabloului în pointer

sizeof_pointer.cppC++
void f(int v[10]) {                 // de fapt: void f(int *v)
    cout << sizeof(v);              // 8 pe 64 de biți: dimensiunea unui POINTER, nu 40!
}                                   // GCC avertizează: -Wsizeof-array-argument

3. Structuri și octeți de aliniere (padding)

Dimensiunea unei struct poate fi mai mare decât suma membrilor, pentru că compilatorul inserează octeți de completare ca să alinieze fiecare membru:

padding.cppC++
struct S { char c; int i; char d; };   // sizeof(S) == 12 : 1 + 3(compl.) + 4 + 1 + 3(compl.)
struct T { int i; char c; char d; };   // sizeof(T) ==  8 : 4 + 1 + 1 + 2(compl.)

Ordonați membrii de la cel mai mare la cel mai mic pentru a economisi memorie. alignof(T) (C++11 / C11 _Alignof) dă alinierea cerută.

4. Biți, nu octeți

Un „octet” (byte) în C are CHAR_BIT biți (<climits>). Pe tot hardware-ul obișnuit sunt 8, dar formal doar ≥ 8. Pentru domenii exacte folosiți std::numeric_limits<int>::max() sau INT_MAX. Pentru dimensiuni exacte folosiți tipurile cu lățime fixă int8_t, int16_t, int32_t, int64_t din <cstdint>.

5. Restricții și operatori înrudiți

  • sizeof nu se poate aplica unui tip funcție, unui tip incomplet (void, o structură doar declarată) sau unui câmp de biți.
  • sizeof pentru o clasă vidă în C++ este cel puțin 1, ca obiectele distincte să aibă adrese distincte.
  • sizeof...(Args) (C++11) numără elementele unui pachet de parametri; este alt operator.
  • Fiind o expresie constantă, poate fi folosit în static_assert(sizeof(int) == 4, "int trebuie sa aiba 32 de biti");.

e1, e2, …, en: evaluate stânga → dreapta; valoarea și tipul sunt ale lui en. Cea mai mică prioritate. Garantează ordinea (punct de secvență). A nu se confunda cu separatorul din declarații și din lista de argumente.

    
?: condițional
c ? e2 : e3: dacă c ≠ 0 se evaluează e2, altfel e3; cealaltă ramură este ignorată. Se asociază de la dreapta, are prioritate mică, deci în cout se pune între paranteze. Tipul este tipul comun al lui e2 și e3.

    
++ --
Prefixat: întâi modifică, apoi folosește (valoarea nouă). Postfixat: întâi folosește, apoi modifică (valoarea veche). Doar pentru variabile (lvalue). Nu folosiți aceeași variabilă de două ori într-o expresie care o incrementează.

    
sizeof
sizeof(tip) / sizeof expr → octeți, de tip size_t. Calculat la compilare, iar operandul nu este evaluat. sizeof(char) == 1; celelalte dimensiuni depind de platformă. Lungimea unui tablou: sizeof v / sizeof v[0].

    
(tip) cast
(T) operand convertește valoarea, nu variabila. float → int trunchiază. (float)(1/2) == 0, dar (float)1/2 == 0.5. În C++ preferați static_cast<T>(e).

    
Prioritate
postfixați > unari (++/-- prefixat, cast, sizeof) > * / % > + - > deplasări > relaționali > egalitate > pe biți > && > || > ?: / atribuire > ,

L6Mediu Cifrele unui număr: /, %, ++ și ?: împreună


L6_cifre.cppC++
#include <iostream>
using namespace std;

int main() {
    int nr;
    cout << "Introduceti un numar natural: ";
    cin >> nr;
    nr = nr >= 0 ? nr : -nr;               // lucram cu |nr|

    int p = 1, nrCifre = 0;
    for (int t = nr; t >= 10; t /= 10)      // p = 10^(cifre-1)
        p *= 10;

    int suma = 0, invers = 0;
    for (int t = nr; p > 0; t %= p, p /= 10) {   // operatorul virgula in pas
        int cifra = t / p;
        cout << cifra << (p > 1 ? " " : "\n");
        suma += cifra;
        nrCifre++;
    }
    for (int t = nr; t > 0; t /= 10)
        invers = invers * 10 + t % 10;

    cout << "cifre: " << nrCifre << ", suma: " << suma << ", invers: " << invers << endl;
    return 0;
}

TermenSemnificație

    
operand / operatorValorile asupra cărora se face o operație / simbolul operației.

    
unar, binar, ternarOperator cu 1, 2 sau 3 operanzi. ?: este singurul operator ternar.

    
prioritate (precedență)Ce operator își leagă primul operanzii când se întâlnesc operatori diferiți.

    
asociativitateSensul de grupare pentru operatori cu aceeași prioritate (stânga → dreapta sau dreapta → stânga).

    
ordine de evaluareOrdinea în care se calculează efectiv operanzii. În cele mai multe cazuri, nespecificată.

    
efect secundarO modificare a stării programului în timpul evaluării unei expresii (atribuire, ++, intrare/ieșire).

    
punct de secvență / secvențiat înainteUn punct în care toate efectele secundare anterioare sunt garantat încheiate (C), respectiv relația de ordine dintre evaluări din C++11.

    
lvalue / rvalueO expresie care desemnează o locație de memorie (o variabilă) / o simplă valoare, fără identitate.

    
prefixat / postfixatOperatorul este scris înaintea (++a) sau după (a++) operandul său.

    
cast (conversie explicită)Conversie cerută explicit: (T)e, T(e), static_cast<T>(e)…

    
promovarea întregilorConversia automată a lui char/short/bool la int în expresii.

    
conversii aritmetice uzualeRegulile care aduc operanzii unui operator binar la un tip comun.

    
trunchiereEliminarea părții fracționare la conversia unui număr real în întreg (spre zero).

    
size_tTipul întreg fără semn întors de sizeof.

    
padding (octeți de completare)Octeți nefolosiți inserați într-o structură pentru aliniere.

    
comportament nedefinit (UB)O construcție pentru care standardul nu impune nicio cerință. Programul poate face orice.

    
nespecificat / definit de implementareUnul dintre mai multe comportamente permise, nedocumentat, respectiv documentat de compilator.

    
evaluare scurtcircuitată&&/|| nu mai evaluează operandul drept dacă cel stâng decide deja rezultatul.

    
maximal munchAnalizorul lexical ia întotdeauna cel mai lung simbol posibil: a+++b → a ++ + b.
