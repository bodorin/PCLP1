1. Limbaje de programare

Un program include: setul de instrucțiuni necesare rezolvării unei probleme și datele și adresele de memorie necesare microprocesorului. Orice prelucrare trebuie să identifice sursa datelor, destinația rezultatelor și operațiile de efectuat.

🔁 Etapele execuției unei instrucțiuni

Un program scris într-un limbaj de nivel înalt este tradus de compilator în cod mașină – secvențe de biți, singurul limbaj pe care calculatorul îl înțelege direct. Scrierea directă în cod mașină este dificilă: programe greu de scris, de înțeles și de depanat, lungi, cu erori greu de localizat și neportabile.

suportul afirmă că „fiecare instrucțiune în cod mașină este o combinație de 4 biți”. În realitate, lungimea instrucțiunilor depinde de procesor; la familia 8086/x86 o instrucțiune are între 1 și 15 octeți (vezi exemplele de mai jos).

Clasificarea limbajelor

Treci cu mouse-ul peste un nivel.

De la C la cod mașină

Apasă pe o linie: vezi instrucțiunea de asamblare și octeții de cod mașină (8086, mod real).

Limbajul de asamblare

Limbaj simbolic, de nivel inferior, situat imediat deasupra limbajului mașină. Fiecărei instrucțiuni îi corespunde un singur cod executabil. Programul care îl traduce în cod mașină este asamblorul. Dependent de calculator.

Limbaje de nivel înalt

Portabile, ușor de învățat, cu notații matematice și cuvinte din engleză. Compilare: program sursă → program obiect; linkeditare: se adaugă module din biblioteci.

Procedurale / orientate pe problemă / naturale

Procedurale (Fortran, Pascal, C++): exprimă procedura de calcul. Orientate pe problemă: definesc scopul, nu pașii. Naturale: limbaj uman, bazate pe cunoaștere (IA).

2. Programarea în limbaj de asamblare – generalități

UCP este caracterizată prin instrucțiunile mașină pe care le execută: ele îi spun unde să găsească datele, când să le citească și cum să le prelucreze. Setul complet de instrucțiuni, împreună cu modurile de adresare (algoritmul de calcul al adresei operanzilor), formează arhitectura setului de instrucțiuni (ISA).

Operații cu memoria: Read și Write

Read (Load/Fetch)

Transferă o copie a conținutului unei locații către procesor; memoria rămâne nemodificată. Procesorul trimite adresa și cere citirea.

Write (Store)

Transferă o informație de la procesor într-o locație, suprascriind vechiul conținut. Procesorul trimite adresa împreună cu datele.

3. Noțiuni de bază: regiștrii microprocesorului 8086

Toate operațiile aritmetice, logice și de acces la memorie se fac prin intermediul regiștrilor. Intel îi clasifică în: regiștri de uz general, regiștri de segment și index, regiștri speciali și flaguri.

4. Setul de instrucțiuni

  • de transfer între memorie și regiștri (LOAD/STORE): de uz general, cu stiva, specifice adreselor;
  • aritmetice; logice și la nivel de bit;
  • de control program (ramificare); pentru controlul procesorului.

MOV și XCHG

mov <destinație>, <sursă>   ·   xchg <op1>, <op2>

mov copiază sursa în destinație fără a modifica sursa. Reguli: destinația este registru sau memorie; sursa este registru, memorie sau valoare imediată; nu ambele memorie; operanzii au aceeași dimensiune; CS nu poate fi destinație; nu se transferă direct între doi regiștri de segment (și nici o valoare imediată într-un registru de segment). xchg interschimbă operanzii; cel puțin unul trebuie să fie registru general; regiștrii de segment nu pot fi operanzi.

✅ Verificator de instrucțiuni

Scrie o instrucțiune; verificatorul spune dacă e corectă și de ce.

Stiva: PUSH și POP

push sursă: SP ← SP − 2, apoi cuvântul sursă se scrie în noul vârf. pop destinație: copiază cuvântul din vârf în destinație, apoi SP ← SP + 2. Stiva funcționează după principiul LIFO (Last In – First Out).

LEA, LDS, LES

lea reg, mem încarcă adresa efectivă a operandului (nu conținutul). lds reg, adr încarcă din memorie, de la adresa adr, un pointer complet: deplasamentul în reg și segmentul în DS; les face același lucru, dar segmentul ajunge în ES.

în suport, efectul lui les este descris tot cu registrul DS; corect: les încarcă segmentul în ES.

Instrucțiuni logice și la nivel de bit

and (A &= B), or (A |= B), xor (A ^= B), not (A = ~A) acționează bit cu bit. test face AND fără să păstreze rezultatul (ca cmp pentru scădere).

Deplasări și rotații

Deplasare: biții se translatează; cei ieșiți se pierd, cu excepția ultimului, reținut în CF. Rotație: biții ieșiți reintră pe partea opusă (ROL, ROR) sau trec prin CF (RCL, RCR).

Scrie sau alege un program și execută-l pas cu pas. Variabilele se declară cu nume dw valoare (cuvânt, 16 biți) sau nume db valoare (octet). Valorile hexazecimale se scriu cu sufixul h (ex. 40h), cele binare cu sufixul b.

Rezumat

  • Un program cuprinde instrucțiuni, date și adrese. Ciclul unei instrucțiuni: preluare, traducere în comenzi, execuție, scrierea rezultatului.
  • Limbaje „low-level” (mașină, asamblare) și „high-level” (procedurale, orientate pe problemă, naturale).
  • ISA = setul de instrucțiuni + modurile de adresare. Operațiile cu memoria: Read (Load/Fetch) și Write (Store).
  • 8086: regiștri generali AX, BX, CX, DX (cu jumătăți H/L), SI, DI, BP, SP; de segment CS, DS, SS, ES; speciali IP și Flags.
  • Instrucțiuni: transfer (mov, xchg, push, pop, lea, lds, les), aritmetice (add, sub, inc, dec, mul, imul, div, idiv, cmp), logice (and, or, xor, not, test), deplasări și rotații (shl, sal, shr, sar, rol, ror, rcl, rcr).

Limbaj de asamblare în programe C

Compilatoarele permit inserarea de cod de asamblare în C (asamblare inline). Sintaxa diferă între compilatoare. Exemplu pentru GCC pe x86 (sintaxa AT&T: sursă, destinație):

#include <stdio.h>

int main(void) {
    int n = 13, m = 29, p;
    __asm__ (
        "movl %1, %%eax\n\t"     /* eax <- n       */
        "addl %2, %%eax\n\t"     /* eax <- eax + m */
        "movl %%eax, %0"         /* p   <- eax     */
        : "=r"(p)                /* iesire         */
        : "r"(n), "r"(m)         /* intrari        */
        : "%eax");               /* registru modificat */
    printf("p = n + m = %d\n", p);
    int x = 5;
    __asm__ ("shll $3, %0" : "+r"(x));   /* x <- x * 8 */
    printf("x << 3 = %d\n", x);
    return 0;
}

Echivalentul în sintaxa Intel (Borland C / Turbo C, 16 biți): asm { mov ax, n; add ax, m; mov p, ax }.
