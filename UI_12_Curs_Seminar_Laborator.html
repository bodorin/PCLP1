1. Funcții: noțiuni teoretice

Definiție. Un subprogram este o secvență de instrucțiuni care rezolvă o anumită sarcină și care poate fi descrisă separat. Poate fi repetată de un număr de ori și executată numai în funcție de anumite condiții. În C++ subprogramele se numesc funcții.

Un program C/C++ este un ansamblu de funcții, fiecare cu o activitate bine definită; main() este tot o funcție și se execută prima. Exemplu de reutilizare a software-ului: o funcție pentru factorial, scrisă o dată, poate fi apelată în orice program.

Avantaje

  • modularizarea problemei (descompunerea în subprobleme)
  • reutilizarea unei secvențe de instrucțiuni în contexte diferite
  • economie de memorie
  • depanare și actualizare mai ușoare

Clasificare

  • după modul de definire: create de utilizator sau predefinite (pow, log, abs…)
  • după valoarea returnată: returnează o valoare în punctul de apel, sau nu returnează (void) – rezultatele se transmit prin parametri

Ca o funcție matematică, o funcție primește valori de intrare (parametri), le prelucrează și generează un rezultat; valori de intrare diferite produc rezultate diferite.

Definiția funcției: anatomie

Treci cu mouse-ul peste părțile definiției:

—
  • tip – tipul valorii întoarse; void dacă funcția nu întoarce nimic. Dacă tip ≠ void, corpul trebuie să conțină return expresie; cu o expresie de același tip.
  • lista parametrilor formali – tipul și numele fiecărui parametru; nu sunt valori concrete, se concretizează la apel.
  • return – la întâlnirea lui se revine în funcția apelantă.
În C++ nu se pot defini funcții imbricate (o funcție în corpul alteia).
O funcție se apelează de obicei după ce a fost definită; dacă definiția vine după apel, înainte de apel trebuie să existe declarația (prototipul): tip nume(lista parametrilor formali);

Apelul funcției

identificator (lista parametrilor efectivi);

La apel, parametrilor formali li se atribuie valorile parametrilor efectivi, apoi se execută corpul funcției. La revenire, controlul trece înapoi în funcția apelantă, la instrucțiunea de după apel. Folosirea parametrilor formali este un prim nivel de abstractizare – abstractizarea prin parametri; acest stil se numește programare procedurală.

🎬 Animație: ce se întâmplă la apel

Observații

  1. Dacă funcția returnează o valoare, apelul poate fi operand într-o expresie.
  2. Între parametrii formali și cei efectivi trebuie să existe o bijecție care păstrează ordinea și tipul.
  3. Parametrii actuali trebuie să fie variabile declarate sau constante (prin valoare se pot folosi și expresii).
  4. Lista parametrilor formali este vidă când nu se face schimb de informație sau acesta se face prin variabile globale.

2. Variabile globale și variabile locale

Memoria alocată unui program este împărțită conceptual în patru segmente. Variabilele pot fi memorate și într-un registru al microprocesorului (acces foarte rapid).

Segmentele memoriei unui program

Treci cu mouse-ul peste un segment.

Atributele unei variabile

  1. tipul
  2. clasa de memorare – locul unde e memorată
  3. vizibilitatea – liniile din care poate fi accesată: la nivel de bloc, de program sau de clasă
  4. durata de viață – timpul în care are alocat spațiu: statică, locală sau dinamică

Rulează exemplele din curs și urmărește panoul de variabile: variabila globală apare separat, iar variabilele locale apar și dispar odată cu cadrul funcției sau cu blocul.

În blocuri diferite se pot declara variabile cu același nume. Dacă o variabilă locală are același nume cu una globală, se folosește declarația cea mai apropiată de locul utilizării.

3. Funcții predefinite: funcțiile matematice

Un prototip descrie funcția ca pe o funcție matematică: int f(int, float); – codomeniul (tipul rezultatului), numele, domeniul (tipurile parametrilor). Prototipurile din același domeniu sunt grupate în fișiere header: funcțiile matematice sunt în <math.h> (în C++: <cmath>).

📈 Explorator de funcții matematice

Generarea numerelor aleatoare

Prototipurile sunt în <stdlib.h>: int rand(void) – întreg aleator între 0 și 32767 (RAND_MAX); void srand(unsigned n) – fixează punctul de pornire al generatorului; randomize() (Borland) – inițializare cu o valoare aleatoare (în C++ standard: srand(time(0))).

Distribuția valorilor rand() % k

în suport, rand() % (b-a) + a este descris ca „număr între a și b”; expresia dă valori din [a, b−1]. Pentru intervalul închis [a, b] se folosește rand() % (b - a + 1) + a.

4. Exemple și aplicații ce utilizează funcții

în suport, funcția triunghi are ; după antet (void triunghi (int n); {), ceea ce nu compilează, iar în ipotenuza numele parametrilor apar despărțite (cateta 1). Aici sunt corectate.

Rezumat

  • Un program C/C++ este un ansamblu de funcții; funcțiile comunică prin parametri și pot returna o valoare.
  • Definiția = antet + corp; declarația (prototipul) = antetul urmat de ;.
  • La apel, parametrii formali primesc valorile parametrilor efectivi; la revenire, execuția continuă după apel.
  • Abstractizarea prin parametri stă la baza programării procedurale.
  • Variabilele sunt locale, globale sau dinamice; ele diferă prin clasa de memorare, vizibilitate și durata de viață.
