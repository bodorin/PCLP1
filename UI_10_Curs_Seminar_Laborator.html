Instrucțiunile limbajului C/C++. Structuri de control auxiliare

Obiectivele unității de învățare nr. 10:

  • Scrierea unor programe C++ simple, utilizând structurile auxiliare prezentate
⏱ Timp mediu de studiu: 3–4 ore · Programele pot fi executate pas cu pas direct în pagină.
Exemplele sunt rescrise în C++ standard (#include <iostream>, int main()). Funcțiile Borland clrscr() și getch() din suport sunt acceptate de simulator, dar nu fac nimic.

1. Selecția multiplă: instrucțiunea switch

Structurile de selecție cu mai multe variante (structuri de selecție extinse) se pot scrie cu switch în loc de mai multe if-uri:

switch (expresie)
{
    case c1: secventa_instructiuni_1; break;
    case c2: secventa_instructiuni_2; break;
    ...
    case cn: secventa_instructiuni_n; break;
    [default: secventa_instructiuni_n+1;]
}

expresie este de tip întreg; c1…cn sunt constante de tip întreg (inclusiv caractere, care sunt coduri întregi). Funcționare: se evaluează expresia; dacă e egală cu ci, se execută secvența i, apoi break trece la instrucțiunea de după switch; dacă nu se potrivește nicio constantă, se execută default. Fără default și fără potrivire, switch nu are efect.

Schema animată: switch cu și fără break

Rolul lui break

Fără break, după ce s-a găsit alternativa potrivită, execuția continuă în alternativele următoare („fall-through”), până la un break sau până la sfârșitul lui switch.

Alternativele se pot grupa când trebuie executată aceeași secvență pentru mai multe valori:

switch (nr_luna_an)
{
    case 2: cout << "are 28 de zile"; break;
    case 4: case 6: case 9: case 11:
        cout << "are 30 de zile"; break;
    default: cout << "are 31 de zile"; break;
}

Exemple de secvențe corecte sintactic

Constantele din case pot fi expresii constante (calculate la compilare). Rulează fiecare exemplu și explică rezultatul:

în suport, alternativa default apare scrisă default: : … (două semne „:”), iar primul exemplu are o paranteză în plus: switch ((k-1)*3)). Formele corecte sunt cele de mai sus. Al patrulea exemplu „corect” din suport (switch(k<'4') cu case 'd'<='9' și case '1'>='4') de fapt nu compilează: ambele constante au valoarea 0, iar valorile din case trebuie să fie distincte.

Secvențe incorecte sintactic

  • switch ((k/2.1)) – expresia este reală, nu întreagă;
  • case sqrt(k): – constanta din case nu poate fi un apel de funcție;
  • switch((k<4)+3.5) – expresie reală;
  • '1' : k++; – lipsește cuvântul cheie case.

Exemplu: codul ASCII al unui caracter alfanumeric

Programul citește un număr natural și spune dacă este codul ASCII al unei litere mici, al unei litere mari sau al unei cifre.

în suport, cuvântul cheie apare ca swich(a) și alternativele nu au break; pentru 97 s-ar afișa toate cele patru mesaje. Varianta corectă are break după fiecare alternativă (compară cele două taburi).

2. Ciclul cu test final: do-while

do
    instructiune
while (expresie);

Funcționare: se execută instrucțiunea, apoi se evaluează expresia; dacă e diferită de 0 se reia instrucțiunea, altfel se trece mai departe. Corpul se execută cel puțin o dată.

Schema logică do-while

Diferența față de while: dacă n = 0, ciclul while (i <= n) nu execută corpul deloc, pe când do … while (i <= n) îl execută o dată (rezultatul ar fi s = 1). Încearcă n = 0 în ambele.

3. Ciclul for (cu număr cunoscut de pași)

for (exp1; exp2; exp3)
    instructiune;

exp1 – inițializare, exp2 – testare, exp3 – reinițializare (incrementare). Funcționare: se execută exp1; se evaluează exp2: dacă e adevărată se execută instrucțiunea, altfel for se termină; se execută exp3 și se revine la testare.

Schema logică for

Echivalența for ↔ while

exp1;
while (exp2)
{
    instructiune;
    exp3;
}

Observații

  1. În exp1 se pot declara și inițializa variabile (for (int i = 0; …)).
  2. Variabila de ciclare poate fi de tip real.
  3. În fiecare secțiune se pot scrie mai multe expresii, separate prin virgulă.
  4. Instrucțiunea poate fi compusă, repetitivă sau de decizie.

Exemple

suportul dă ca exemplu corect for(int i=5,j++;…); acesta nu compilează (j++ nu poate apărea într-o declarație). Varianta corectă este for (int i = 5; i <= 10; i++, j++). De asemenea, în C++ standard o variabilă declarată în for(int i…) nu mai există după ciclu; exemplul cu ; după for declară deci i înaintea ciclului.

Rezumat

  • switch permite selecția unei variante din mai multe; fără break execuția continuă în alternativele următoare; alternativele se pot grupa.
  • do … while este ciclul condiționat posterior: corpul se execută cel puțin o dată.
  • for este ciclul condiționat anterior, cu număr cunoscut de pași: inițializare, testare, reinițializare.
