1. Structura secvențială

Orice program C/C++, indiferent de complexitate, poate fi scris folosind una, două sau toate cele trei structuri de bază: secvența, selecția și repetiția. Ele se numesc structuri de control (structuri logice), pentru că stabilesc ordinea în care calculatorul execută instrucțiunile.

Structura secvențială execută instrucțiunile una după alta, în ordinea scrierii, fără ramificări sau salturi. Este folosită în toate programele.

Figura 1 – structura secvențială (animată)

Instrucțiunea compusă (blocul)

Un grup de instrucțiuni separate prin ; și cuprinse între acolade { }. Blocul poate conține declarații locale, valabile doar în interiorul lui:

{ declarații și definiții locale blocului; instrucțiuni }
După execuția ultimei instrucțiuni din bloc, variabila aux nu mai există. Urmărește panoul „Variabile”: aux apare la intrarea în bloc și dispare la ieșire.

2. Structura decizională (de selecție)

Indică faptul că într-un punct al programului trebuie luată o decizie în funcție de anumite condiții, urmată de acțiunea corespunzătoare. În C/C++ există trei structuri decizionale: if (decizia simplă), if/else și switch (unitatea 10).

Structura if (decizia simplă)

if (expresie) instrucțiune;

Funcționare: se evaluează expresia. Dacă are o valoare diferită de 0 (adevărat), se execută instrucțiunea; altfel se trece la instrucțiunea următoare lui if. Pentru mai multe instrucțiuni pe ramura „adevărat” se folosește un bloc { … }.

Figura 2 – structura if

Structura if/else

if (expresie) instrucțiune1; else instrucțiune2;

Funcționare: dacă expresia e diferită de 0 se execută instrucțiune1, altfel instrucțiune2; apoi se trece la instrucțiunea următoare.

Figura 3 – structura if/else

Observații

  1. Înainte de else se pune ; dacă instrucțiune1 este simplă; nu se pune dacă este un bloc { }.
  2. Ramurile pot conține alte instrucțiuni if (if-uri imbricate).
  3. Ramurile pot conține instrucțiuni compuse.

Secvențe corecte sintactic:

k=3; if (!0) k++; else k--;
if (1) cout<<"da"; else cout<<"nu";
k=3; if (!k); else;
if (0); else cout<<"nu";

If-uri imbricate: calculul expresiei e

e = x + y, dacă z > 0  ·  e = x · y, dacă z = 0  ·  e = x − y, dacă z < 0
în suport apare if (z= =0); operatorul corect este ==, fără spațiu.

3. Structura repetitivă: ciclul cu test inițial

Ciclul while are un număr necunoscut de pași și este condiționat anterior:

while (expresie) instrucțiune;

Funcționare: se evaluează expresia; dacă valoarea e diferită de 0, se execută instrucțiunea și se revine la evaluare; dacă e 0, se trece la instrucțiunea următoare.

4. Exemple și aplicații

Pentru fiecare secvență, scrie ce crezi că se afișează, apoi verifică și urmărește execuția pas cu pas.

Rezumat

  • Orice program C/C++ poate fi scris folosind secvența, selecția și repetiția.
  • Structura secvențială execută instrucțiunile în ordine, fără ramificări sau salturi.
  • Instrucțiunea compusă (blocul) grupează instrucțiuni între acolade { }.
  • Structurile decizionale: if, if/else, switch; else se asociază cu cel mai apropiat if.
  • while este ciclul cu test inițial: corpul poate să nu se execute niciodată (condiție inițial falsă) sau să se execute la infinit (condiție mereu adevărată).
