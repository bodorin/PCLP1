M1

De la întrerupător la bit

Nivel 1 · Fundamente

La final vei ști: ce înseamnă 0 și 1 într-un circuit, de ce două valori sunt suficiente și cum se traduc „și”, „sau”, „nu” din vorbire în electricitate.

Două stări, nimic la mijloc

Un calculator manipulează informație binară: fiecare fir dintr-un circuit digital are, în orice moment, una din două stări. Le numim 1 (TRUE, adevărat, tensiune prezentă) și 0 (FALSE, fals, tensiune absentă). O variabilă care poate lua doar aceste două valori se numește variabilă logică (sau booleană, după matematicianul George Boole).

Bec
aprins = 1, stins = 0

„Plouă.” adevărat = 1, fals = 0

Analogia cu întrerupătoarele

Cele trei operații de bază ale algebrei booleene au un corespondent fizic foarte simplu. Apasă pe întrerupătoare și urmărește becul.

Serie → ȘI (AND)

Becul se aprinde doar dacă A și B sunt închise.

Paralel → SAU (OR)

Becul se aprinde dacă A sau B (sau ambele) sunt închise.

Contact inversat → NU (NOT)

Becul arde când A nu este apăsat.

Intuiție

Serie = „toate trebuie să lase curentul să treacă”. Paralel = „ajunge un singur drum liber”. Acest model mental te va ajuta să ghicești corect multe legi din M4 înainte să le demonstrezi.

Circuit combinațional și circuit secvențial

Un circuit logic are una sau mai multe borne de intrare și una sau mai multe borne de ieșire. La intrări se aplică semnale 0/1 care reprezintă variabile booleene; la ieșiri apar valorile unor funcții booleene de aceste variabile.

Combinațional

Ieșirile depind numai de valorile actuale ale intrărilor. Aceleași intrări dau mereu aceleași ieșiri. Acesta este subiectul unității.

Fiecare ieșire este o funcție: y1 = y1(x1, …, xn).

Secvențial

Ieșirile depind și de valorile precedente ale intrărilor: circuitul are memorie (bistabile, registre, numărătoare). Le vei întâlni mai târziu; aici doar le recunoaștem existența.

Reține

0/1 = FALSE/TRUE. Serie = ȘI, paralel = SAU, contact inversat = NU. Un circuit combinațional nu are memorie: ieșirea e complet determinată de intrările de acum.

M3

Expresii booleene și tabele de adevăr

Nivel 1 → 2

La final vei ști: să citești corect o expresie (ordinea operațiilor), să o evaluezi pentru valori date și să îi construiești tabela de adevăr completă, cu coloane intermediare.

Definiție

Se numește expresie booleană orice expresie rezultată prin aplicarea de un număr finit de ori a operațiilor +, ·, ‾ asupra unor elemente determinate (constantele 0 și 1) sau nedeterminate (variabile) ale unei algebre booleene.

Exemple: x*y + !y*!z, !(x+y)*z, a + 0. Nu sunt expresii booleene: x + (operație incompletă) sau 2x (2 nu există în algebra booleană).

Ordinea operațiilor

La fel ca în aritmetică, unde înmulțirea se face înaintea adunării, și aici există o prioritate:

‾ (NU)  ›  · (ȘI)  ›  + (SAU)

Parantezele schimbă ordinea. Bara de negație lungă acționează ca o paranteză: tot ce e sub ea se calculează întâi, apoi se neagă rezultatul.

Fără paranteze

x + y*z pentru x=1, y=0, z=0:
întâi ȘI: y*z = 0*0 = 0, apoi SAU: 1 + 0 = 1.

Cu paranteze

(x+y)*z pentru aceleași valori:
întâi paranteza: 1 + 0 = 1, apoi ȘI: 1*0 = 0. Rezultat diferit.
Atenție

!(x*y) nu este același lucru cu !x*!y. Prima neagă produsul, a doua înmulțește negațiile. Pentru x=1, y=0: !(1*0) = !0 = 1, dar !1*!0 = 0*1 = 0. Legătura corectă dintre ele este dată de legile lui De Morgan (M4).

Evaluarea pas cu pas: arborele expresiei

Orice expresie este un arbore: frunzele sunt variabilele, nodurile interioare sunt operațiile, iar rădăcina dă rezultatul. Valorile „urcă” de la frunze spre rădăcină. Mai jos, expresia f = x*y + !y*!z. Comută variabilele și urmărește cum se propagă valorile; ramurile care poartă 1 sunt colorate.

Legătura cu circuitele

Arborele este deja un circuit: fiecare nod devine o poartă, fiecare muchie un fir. Întoarce desenul cu rădăcina spre dreapta și obții schema din exemplul 3 al suportului (M7).

M4

Legile algebrei booleene

Nivel 2 · Intermediar

La final vei ști: cele 10 perechi de legi din suport, ce spun în cuvinte, cum se verifică cu tabela de adevăr și cum le folosești ca „unelte” de simplificare.

De cele mai multe ori, o expresie booleană nu este în forma ei cea mai simplă. Simplificarea se face pe baza unor axiome (legi) de bază și a relațiilor deduse din ele. Fiecare lege vine în pereche: a doua formă se obține din prima schimbând · cu + și 0 cu 1. Aceasta este dualitatea.

Principiul dualității

Dacă o egalitate e adevărată, rămâne adevărată și după ce înlocuiești peste tot · ↔ + și 0 ↔ 1 (variabilele rămân neschimbate). Așa că, practic, ai de învățat doar jumătate din legi.

Apasă „Verifică” sub orice lege: vezi tabela de adevăr a ambelor părți. Coloanele identice sunt dovada.

M5

Funcții booleene și forme canonice

Nivel 2 · Intermediar

La final vei ști: ce este o funcție booleană, câte funcții există de n variabile, ce sunt produsele elementare, mintermii și maxtermii, și cum scrii direct din tabel forma canonică disjunctivă (FCD) și conjunctivă (FCC).

Definiție

Se numește funcție booleană (sau funcție binară) de n variabile o funcție f : B2 × B2 × … × B2 → B2, unde B2 = {0, 1}. Fiecărei combinații de n elemente (0 sau 1) funcția îi asociază un element din B2, numit valoarea funcției pentru sistemul de valori considerat.

O variabilă care ia valori în B2 se numește variabilă booleană. Așadar, o funcție booleană este complet descrisă de coloana ei din tabelul de adevăr. Expresia este doar una dintre multele „rețete” care produc acea coloană.

Ideea centrală

O funcție = o coloană de 0 și 1. Mai multe expresii diferite pot da aceeași coloană; atunci reprezintă aceeași funcție. Simplificarea înseamnă să găsești, dintre ele, rețeta cea mai scurtă.

Câte funcții există?

Tabelul are 2n rânduri și pe fiecare rând funcția poate valora 0 sau 1, independent. Deci există 22n funcții distincte de n variabile: 4 pentru n = 1, 16 pentru n = 2, 256 pentru n = 3, 65 536 pentru n = 4.

Iată toate cele 16 funcții de două variabile. Fiecare bandă arată valorile pentru AB = 00, 01, 10, 11. Le recunoști pe cele din M2?

Produs elementar, minterm, maxterm

Produs elementar

Un produs de variabile booleene sau de complemente ale lor, fără ca aceeași variabilă să apară de mai multe ori.

Da: x*!y, !x*y*z, z. Nu: x*x*y, x*!x.

Minterm (mi)

Un produs elementar care conține toate variabilele funcției. Valorează 1 pe un singur rând al tabelului: rândul i.

Regula: variabila apare simplă dacă pe acel rând e 1, negată dacă e 0. Rândul 101 → x*!y*z = m5.

Maxterm (Mi)

O sumă care conține toate variabilele și valorează 0 pe un singur rând. Regula e inversă: variabila apare negată dacă pe acel rând e 1. Rândul 101 → !x + y + !z = M5. Observă că M5 = !m5 (De Morgan).

Forma normală disjunctivă și forma canonică disjunctivă

Se numește formă normală disjunctivă (FND) a unei expresii booleene o sumă de produse elementare egală cu expresia dată.

Dacă fiecare produs conține toate variabilele (deci e un minterm), forma se numește forma canonică disjunctivă (FCD). FCD este unică pentru o funcție dată.

Rețeta FCD (direct din tabel)

  1. Marchează rândurile pe care funcția valorează 1.
  2. Pentru fiecare astfel de rând, scrie mintermul lui: variabila cu valoarea 1 apare simplă, cea cu valoarea 0 apare negată.
  3. Adună (SAU) toți acești mintermi.

Rețeta FCC (forma canonică conjunctivă)

  1. Marchează rândurile pe care funcția valorează 0.
  2. Pentru fiecare, scrie maxtermul: variabila cu valoarea 0 apare simplă, cea cu valoarea 1 apare negată.
  3. Înmulțește (ȘI) toți acești maxtermi.

Constructor interactiv

Apasă pe celulele din coloana f ca să alegi orice funcție de trei variabile. FCD, FCC și forma minimă se recalculează instantaneu. Pornim de la funcția „exact doi din trei”, cea din problemele 1–2 ale testului.

Atenție

FCD este corectă, dar de obicei lungă: fiecare termen are toate variabilele. Pentru un circuit vrem forma cea mai scurtă. Asta e tema modulului următor.

Reține

Funcție = coloană. Există 22n funcții de n variabile. FCD = suma mintermilor rândurilor cu 1. FCC = produsul maxtermilor rândurilor cu 0. Orice funcție booleană se poate scrie, deci, numai cu ȘI, SAU, NU.

M6

Simplificarea funcțiilor booleene

Nivel 2 → 3

La final vei ști: ce înseamnă „mai simplu”, algoritmul de aducere la forma normală disjunctivă, șase strategii algebrice de simplificare și metoda grafică a diagramelor Karnaugh.

Ce înseamnă „mai simplu”?

Suportul dă un criteriu precis: o expresie este mai simplă decât alta dacă numărul de apariții ale variabilelor este mai mic. De obicei se caută cea mai simplă expresie în formă normală disjunctivă echivalentă cu cea dată.

Înainte

f = x*y + x*!y + !x*y*z
apariții de variabile: 7

După

f = x + y*z
apariții de variabile: 3

De ce contează: fiecare apariție de variabilă este un fir care intră într-o poartă. Mai puține apariții înseamnă mai puține porți, un circuit mai ieftin, mai mic și mai rapid. Vei vedea diferența concret în M7.

Algoritmul de aducere la forma normală disjunctivă

  1. Dacă operația de complementare este aplicată unor expresii (bare lungi), aplici formulele lui De Morgan până când barele rămân doar pe variabile.
  2. Distribui operația „·” față de „+” de câte ori este cazul (desfaci parantezele).
  3. Elimini produsele care se anulează (conțin x*!x) sau se repetă, și variabilele care apar de două ori în același produs.

Verificarea prin tabelă

Șase strategii algebrice

S1 · factor comun + complementaritate
x*y + x*!y = x*(y+!y) = x

Doi termeni care diferă printr-o singură variabilă (o dată simplă, o dată negată) se unesc, iar variabila dispare. Este exact ce face diagrama Karnaugh vizual.

S2 · absorbția
x + x*y = xx*(x+y) = x

Dacă un termen îl „conține” pe altul (are toate variabilele lui, plus altele), termenul mai lung dispare.

S3 · absorbția complementului (D1)
x + !x*y = x + y

Literalul negat !x e inutil lângă x: îl ștergi.

S4 · reutilizarea unui termen (idempotență)
x*y*z + !x*y*z + x*!y*z

Scrii x*y*z de două ori (a = a+a) și îl împerechezi cu fiecare vecin: (xyz + !xyz) + (xyz + x!yz) = y*z + x*z.

S5 · consensul (D2)
x*y + !x*z + y*z = x*y + !x*z

Când doi termeni conțin x și !x, produsul „restului” lor e redundant.

S6 · De Morgan pentru bare lungi
!(!x*y + !x*!y + !y) = x*y

Simplifică întâi interiorul (!x + !y), apoi aplică De Morgan și dubla negație. E problema 4 din test.

Capcana algebrei

Metoda algebrică cere „inspirație”: trebuie să vezi ce termeni să grupezi. Nu ai garanția că ai ajuns la forma minimă. Metoda următoare e mecanică și îți dă garanția aceasta pentru funcții de până la 4 variabile.

Diagrame Karnaugh

Dincolo de suport

Diagramele Karnaugh nu apar în suportul de curs. Sunt metoda grafică standard de simplificare și îți permit să verifici rapid orice simplificare algebrică. Le includem pentru nivelul de performanță maximă.

O diagramă Karnaugh este tabela de adevăr rearanjată ca o grilă, astfel încât oricare două celule vecine să difere printr-o singură variabilă. Pentru asta, rândurile și coloanele se numerotează în cod Gray: 00, 01, 11, 10 (nu 00, 01, 10, 11).

De ce funcționează: două celule vecine cu 1 corespund la doi mintermi care diferă printr-o variabilă, iar x*y + x*!y = x (strategia S1). O grupare de 2 celule elimină o variabilă, una de 4 elimină două, una de 8 elimină trei.

Regulile grupării

  1. Grupezi doar celule cu 1 (și, opțional, celule X, „indiferente”, dacă ajută).
  2. Grupurile sunt dreptunghiuri cu 1, 2, 4, 8 sau 16 celule (puteri ale lui 2).
  3. Fiecare grup trebuie să fie cât mai mare.
  4. Folosești cât mai puține grupuri; ele se pot suprapune.
  5. Harta „se închide” la margini: coloana din stânga e vecină cu cea din dreapta, rândul de sus cu cel de jos (cele 4 colțuri formează un grup).
  6. Citirea unui grup: păstrezi doar variabilele care nu își schimbă valoarea în interiorul grupului (1 → simplă, 0 → negată).

Exemplu ghidat: funcția din exemplul 1 al suportului

f = x*y + x*!y + !x*y*z are 1 pe rândurile 3, 4, 5, 6, 7. În diagramă, rândul x = 1 este plin (grup de 4 → rămâne doar x), iar celula 3 se grupează cu 7 (rămâne y*z). Rezultat: f = x + y*z, exact ce dă și algebra.

Diagrama este interactivă: apasă celulele, alege alt exemplu din listă sau trece la 4 variabile. Grupările punctate trec peste margine.

Reține

Criteriul: mai puține apariții de variabile. Algoritmul FND: De Morgan → distributivitate → eliminare. Karnaugh: cod Gray, dreptunghiuri de 2k, cât mai mari, cât mai puține, harta se închide la margini.

M7

De la expresie la circuit (și înapoi)

Nivel 3 · Avansat

La final vei ști: să desenezi circuitul oricărei expresii (sinteză), să scrii expresia oricărui circuit (analiză) și să compari două circuite după cost.

De ce ajung trei porți

Orice funcție booleană se poate exprima cu ajutorul celor trei operații „·”, „+”, „‾” (am văzut în M5: FCD folosește doar ele). Rezultă că orice circuit logic simplu (circuit combinațional cu o singură bornă de ieșire) se poate realiza combinând circuitele elementare ȘI, SAU, NU. Combinând și mai departe obținem ȘI-NU, SAU-NU. Toate acestea se numesc porți logice.

Aceeași funcție are mai multe expresii, deci mai multe circuite. De aici importanța simplificării: aceeași funcție se poate realiza și cu scheme mai simple.

Cum citești schemele de aici

  • Fiecare intrare are o magistrală verticală. Firele către porți pleacă orizontal din ea; punctul marchează legătura.
  • Magistralele marcate cu bară (de ex. !x) pornesc dintr-un inversor desenat în partea de sus.
  • Firele care se încrucișează fără punct nu sunt legate.
  • Firele portocalii poartă 1. Porțile cu ieșirea 1 se colorează și ele.

Metoda de sinteză (expresie → circuit)

  1. Simplifică expresia (M6). Fiecare apariție de variabilă în minus este un fir în minus.
  2. Identifică variabilele negate: fiecare cere un inversor (o magistrală cu bară).
  3. Desenează câte o poartă ȘI pentru fiecare produs cu cel puțin două literale.

M8

Porți universale: NAND și NOR

Nivel 3 → 4

La final vei ști: de ce se poate construi orice circuit numai din porți NAND (sau numai din NOR) și cum transformi sistematic o expresie într-o schemă NAND sau NOR, cum cer problemele 9 și 10 din test.

De ce contează

În tehnologia reală, poarta NAND este cea mai ieftină și mai rapidă de fabricat. Un circuit integrat clasic (de exemplu seria 7400) conține patru porți NAND identice. Dacă poți construi totul din NAND, ai nevoie de un singur tip de piesă.

ȘI, SAU, NU construite numai din NAND

NU din NAND

Legi intrările împreună: !(A*A) = !A.

ȘI din NAND

NAND urmat de un NU-din-NAND: !!(A*B) = A*B.

SAU din NAND

Negi intrările, apoi NAND: !(!A*!B) = A+B.

ȘI, SAU, NU construite numai din NOR

NU din NOR

!(A+A) = !A.

SAU din NOR

!!(A+B) = A+B.

ȘI din NOR

!(!A+!B) = A*B.

Deoarece ȘI, SAU, NU sunt suficiente pentru orice funcție (M5), iar fiecare se poate construi din NAND, rezultă că NAND singură este suficientă. La fel NOR. Spunem că sunt porți universale.

Tehnica dublei negații

Toate problemele de sinteză NAND/NOR se rezolvă cu aceeași idee: pui două bare peste expresie (nu schimbă nimic, !!a = a), apoi „cobori” bara de jos cu De Morgan până când fiecare bară acoperă un produs (pentru NAND) sau o sumă (pentru NOR).

Fiecare !(…·…) este o poartă NAND. Concluzia practică, foarte utilă: un circuit ȘI–SAU pe două niveluri devine NAND–NAND înlocuind pur și simplu toate porțile cu NAND (literalele izolate care intră direct în SAU trebuie negate).

Rețeta în patru pași

  1. Adu expresia la forma potrivită: sumă de produse pentru NAND, produs de sume pentru NOR.
  2. Pune două bare peste toată expresia.
  3. Aplică De Morgan pe bara de jos; repetă pe sub-expresii până când fiecare bară acoperă exact o operație de tipul dorit.
  4. Fiecare bară devine o poartă. Inversoarele se fac din aceeași poartă cu intrările legate împreună.

Reține

NAND și NOR sunt universale. Inversor = poartă cu intrările legate. ȘI–SAU pe două niveluri → NAND–NAND. SAU–ȘI → NOR–NOR. Instrumentul: dubla negație + De Morgan.

Circuite logice complexe

Nivel 3 → 4

La final vei ști: cum funcționează decodificatorul, codificatorul și sumatoarele (elementar și pe n biți) și cum li se deduc ecuațiile din tabel.

Decodificatorul

Decodificatoarele sunt destinate să recunoască diferitele combinații de valori ale variabilelor de la intrare. Fiecărei combinații îi corespunde o ieșire: un cod de intrare cu n biți este identificat prin activarea unei singure ieșiri din cele m = 2n.

Decodificatorul 2 → 4 din suport: fiecare ieșire este un minterm al intrărilor, realizat cu o poartă ȘI. Apasă pe x1 și x2: întotdeauna se aprinde exact un bec.

Unde îl întâlnești

Când procesorul accesează memoria, un decodificator transformă adresa binară într-un singur semnal „selectează această celulă”. Un decodificator 3 → 8 are 8 porți ȘI cu câte 3 intrări; unul cu 10 biți de adresă selectează una din 1024 de celule.

Codificatorul

Codificatoarele realizează operația inversă: primesc o singură intrare activă și produc codul ei binar. Sunt compuse din câte o poartă SAU pentru fiecare bornă de ieșire. Codificatorul din suport transformă o cifră zecimală 0–9 în cod binar pe 4 biți (BCD).

Deducerea ecuațiilor. Citește tabelul pe coloane: ieșirea xk trebuie să fie 1 exact pentru cifrele care au 1 în acea coloană.

„8 + 9” înseamnă „linia cifrei 8 SAU linia cifrei 9”. Cifra 0 nu e legată nicăieri: codul ei este 0000.

Sumatorul pe n biți

Un sumator pentru numere binare cu n cifre este alcătuit din n sumatoare elementare, câte unul pe fiecare coloană. Transportul ieșit dintr-o coloană (t′k) devine transportul de intrare al coloanei din stânga (tk+1). Mai jos, sumatorul pe 4 biți din suport. Apasă biții operanzilor și urmărește cum „curge” transportul de la dreapta la stânga, exact ca la adunarea pe hârtie.

Atenție la viteză

Fiecare coloană trebuie să aștepte transportul coloanei din dreapta. La 64 de biți, transportul poate traversa 64 de etaje. De aceea procesoarele reale folosesc scheme de „anticipare a transportului”. Ideea de bază rămâne însă sumatorul elementar de aici.

Reține

Decodificator: n intrări → 2n ieșiri, câte un ȘI per minterm, exact o ieșire activă. Codificator: inversul, câte un SAU per bit de ieșire. Sumator elementar: S = a^b^t, t′ = ab + at + bt. Sumatorul pe n biți leagă n sumatoare elementare în lanț.

Program 1 · tabela de adevăr a unei funcții

#include <stdio.h>

int main(void) {
    int x, y, z, f;
    printf(" x y z | f\n");
    for (x = 0; x <= 1; x++)
        for (y = 0; y <= 1; y++)
            for (z = 0; z <= 1; z++) {
                f = (x && y) || (!y && !z);   /* f = x·y + y̅·z̅ */
                printf(" %d %d %d | %d\n", x, y, z, f);
            }
    return 0;
}

Cele trei bucle imbricate generează exact numărarea binară de la 000 la 111 din M3.

#include <stdio.h>

/* sumatorul elementar: întoarce S, scrie transportul în *tp */
int sumator(int a, int b, int t, int *tp) {
    *tp = (a & b) | (a & t) | (b & t);   /* t' = ab + at + bt */
    return a ^ b ^ t;                     /* S  = a ⊕ b ⊕ t    */
}

int main(void) {
    int A = 6, B = 7, t = 0, S = 0, k;
    for (k = 0; k < 4; k++) {               /* de la bitul 0 spre bitul 3 */
        int ak = (A >> k) & 1, bk = (B >> k) & 1, tp;
        S |= sumator(ak, bk, t, &tp) << k;
        t = tp;                               /* transportul trece la coloana următoare */
    }
    S |= t << 4;                              /* transportul final devine bitul 4 */
    printf("%d + %d = %d\n", A, B, S);       /* 6 + 7 = 13 */
    return 0;
}

a) Rezolvare și circuit
F1 = (A+B)*(C+!D)expresia dată
= !(!A*!B)*!(!C*D)De Morgan pe fiecare sumă + dubla negație

= !!(A + B*C + B*!D)dubla negație

Comparat cu 9b: aceeași funcție, altă schemă. Aici sunt două niveluri de NAND-uri utile (plus inversoare), deci un circuit mai rapid.

b) Rezolvare și circuit

S2

Exerciții suplimentare, pe niveluri

Exerciții noi, ordonate de la ușor la greu. Dacă le rezolvi pe toate fără să deschizi soluțiile, ești la nivelul maxim cerut de unitate.

Nivel 1 · Fundamente

E1Evaluare
Calculați E = x + !y*z pentru (x, y, z) = (0, 0, 1) și (0, 1, 1).
Soluție

(0,0,1): 0 + !0*1 = 0 + 1*1 = 1. (0,1,1): 0 + !1*1 = 0 + 0*1 = 0. Ordinea: întâi negația, apoi ȘI, apoi SAU.

E2Numărare
Câte rânduri are tabela unei funcții de 5 variabile? Câte funcții booleene distincte de 3 variabile există?
Soluție

25 = 32 de rânduri. Funcții de 3 variabile: tabelul are 8 rânduri, fiecare cu 2 valori posibile, deci 28 = 256.

E3Tabel cu coloane intermediare
Construiți tabela de adevăr pentru f = !(x+y)*z.
Soluție

f = 1 doar pe rândul 001: x și y sunt 0, z este 1.

E6Forma canonică
O funcție de trei variabile valorează 1 pe rândurile 1, 2, 4, 7. Scrieți FCD-ul și încercați să o simplificați.
Soluție

Rândurile 001, 010, 100, 111: f = !x*!y*z + !x*y*!z + x*!y*!z + x*y*z.

Nu se poate simplifica ca sumă de produse: oricare doi mintermi diferă prin cel puțin două variabile (în Karnaugh, tablă de șah). Este funcția de paritate f = x^y^z, aceeași ca suma S a sumatorului complet.

E7Absorbție
Simplificați x + x*y + x*!y*z.
Soluție

Ambii termeni lungi conțin x, deci sunt absorbiți: x + x*y = x, apoi x + x*!y*z = x. Rezultat: x.

E10Karnaugh pe 4 variabile
Simplificați f(A,B,C,D) = Σm(0, 2, 5, 7, 8, 10, 13, 15).
Soluție interactivă

Nivel 4 · Proiectare

E11Detector de numere prime
Un număr N de la 0 la 15 este dat în binar pe 4 biți ABCD (A cel mai semnificativ). Proiectați un circuit cu ieșirea 1 dacă N este prim.
Soluție

Faza 1–2. Numerele prime sub 16: 2, 3, 5, 7, 11, 13. Deci f = Σm(2, 3, 5, 7, 11, 13).

Faza 3. Karnaugh (interactiv):

O formă minimă: f = !A*!B*C + !A*C*D + B*!C*D + !B*C*D (4 termeni, 12 literali). Există și o altă formă minimă la fel de bună: !A*!B*C + !A*B*D + B*!C*D + !B*C*D. Ambele sunt corecte.

Faza 4. Scrie expresia în Laboratorul din S4 și obții automat circuitul ȘI–SAU și varianta NAND.

E12Comparator de egalitate
Proiectați un circuit care primește două numere de 2 biți (x1x2 și x3x4) și dă 1 dacă sunt egale.
Soluție

Numerele sunt egale dacă cifrele corespunzătoare sunt egale: E = !(x1^x3)*!(x2^x4). „Cifre egale” = poarta XNOR.

Combinat cu comparatorul din M10 (n1 > n2), obții un comparator complet: mai mare, egal, mai mic.

E13Convertor binar → cod Gray
Codul Gray (folosit la diagramele Karnaugh) are proprietatea că două numere consecutive diferă printr-un singur bit. Proiectați convertorul pe 3 biți b2b1b0 → g2g1g0.
Soluție

Din tabel se observă: g2 = b2, g1 = b2^b1, g0 = b1^b0. Fiecare bit Gray spune dacă doi biți binari vecini diferă.

E14Semiscăzătorul
Proiectați un circuit care calculează a − b pentru doi biți: diferența D și împrumutul Î (1 dacă trebuie „împrumutat” de la coloana din stânga).
Soluție

0−0 = 0, 1−0 = 1, 1−1 = 0, 0−1 = 1 cu împrumut. Deci D = a^b (ca la sumă!) și împrumutul apare doar pentru a = 0, b = 1: Î = a·b.

E15Teorema consensului
Demonstrați algebric că x*y + !x*z + y*z = x*y + !x*z.
Soluție
x*y + !x*z + y*z = x*y + !x*z + y*z*(x+!x)element neutru: yz = yz*1, 1 = x+!x
= x*y + !x*z + x*y*z + !x*y*zdistributivitate
= x*y*(1+z) + !x*z*(1+y)factor comun
= x*y + !x*z1+a = 1

S5

Fișă recapitulativă

Operații și porți

Legi esențiale

  • a+!a = 1, a*!a = 0
  • a+1 = 1, a*0 = 0
  • a+a = a, a*a = a
  • !(a+b) = !a*!b, !(a*b) = !a+!b
  • a+a*b = a, a*(a+b) = a
  • a+!a*b = a+b
  • a+b*c = (a+b)*(a+c)
  • xy + !xz + yz = xy + !xz

Metode

  • Tabel: 2n rânduri, numărare binară, coloane intermediare.
  • FCD: minterm pentru fiecare rând cu 1 (1 → simplu, 0 → negat).
  • FCC: maxterm pentru fiecare rând cu 0 (0 → simplu, 1 → negat).
  • FND: De Morgan → distributivitate → eliminare.
  • Karnaugh: cod Gray, grupuri de 2k, cât mai mari, harta se închide.
  • NAND/NOR: dublă negație + De Morgan.
  • Proiectare: variabile → tabel → minimizare → circuit → verificare.

Rezumat (după suport)

Se numește expresie booleană orice expresie rezultată prin aplicarea de un număr finit de ori a operațiilor +, ·, ‾ unor elemente determinate sau nedeterminate ale unei algebre booleene. O funcție booleană de n variabile asociază fiecărei combinații de n valori 0/1 o valoare din B2. O problemă importantă este găsirea unei forme cât mai simple pentru expresiile funcțiilor; de obicei se caută forma normală disjunctivă (sumă de produse elementare) cea mai simplă. Circuitele calculatorului sunt în mare parte circuite logice, care realizează fizic funcțiile booleene. Deoarece orice funcție se exprimă cu „·”, „+”, „‾”, orice circuit logic simplu se poate realiza combinând porțile ȘI, SAU, NU; prin combinarea lor se obțin și ȘI-NU, SAU-NU.
