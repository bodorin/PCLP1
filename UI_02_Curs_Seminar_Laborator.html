1. Reprezentarea informației numerice. Sistemul binar

Calculatoarele și circuitele digitale prelucrează informația în format binar. Fiecare caracter are asociat un cod binar de 7 sau 8 biți. De exemplu, șirul 1000010 reprezintă 66 (zecimal), litera B în cod ASCII și 42 (zecimal) în cod BCD.

⚡ Componente binare

Un comutator este on (1) sau off (0); un tranzistor MOS de memorare conduce (1 logic) sau nu (0 logic).

🧮 Calcule simple

Doar două cifre (biți) ⇒ implementare hardware simplă și calcule mai exacte.

♾ Universal

Tot ce se poate reprezenta în zecimal se poate reprezenta și în binar.

Deoarece numerele binare necesită mulți biți, se folosesc și sistemele octal și hexazecimal, care „comprimă” șirurile lungi de biți.

Sistem de numerațieBazaCifre
Zecimal100 1 2 3 4 5 6 7 8 9
Binar20 1
Octal80 1 2 3 4 5 6 7
Hexazecimal160 1 2 3 4 5 6 7 8 9 A B C D E F

Acestea sunt sisteme poziționale: valoarea unei cifre depinde de poziția ei în număr. Fiecare cifră se înmulțește cu o putere a bazei:

r = an·bn + an−1·bn−1 + … + a0·b0 + f1·b−1 + … + fm·b−m,   0 ≤ ai, fi < b,  an ≠ 0

2. Conversii între sisteme de numerație

Există două grupuri importante de conversii: (1) din zecimal în baza r și (2) din baza r în zecimal.

Zecimal → binar (numere întregi): împărțiri succesive

Se împarte succesiv la 2 (baza) până când câtul devine 0. Fiecare rest dă o nouă cifră, începând cu cea mai puțin semnificativă. Același algoritm funcționează pentru orice bază.

Zecimal → binar (numere subunitare): înmulțiri succesive

Se înmulțește succesiv cu 2. Partea întreagă a fiecărui rezultat dă o nouă cifră, începând cu cea mai semnificativă. Te poți opri când ai atins precizia dorită.

Zecimal → binar (numere reale)

Un număr real x = [x] + {x} (parte întreagă + parte fracționară). Se convertesc separat cele două părți, apoi se alătură cu virgula între ele:

147(10) → 10010011(2) 0.37(10) → 0.01011110(2) ─────────────────────────────── 147.37(10) → 10010011.01011110(2)

Binar → zecimal

Se adună produsele dintre fiecare bit și puterea lui 2 corespunzătoare poziției: 20, 21, 22… spre stânga și 2−1, 2−2… spre dreapta virgulei. Apasă pe biți pentru a-i comuta:

Tabel: fracții zecimale și echivalentul lor în baza 2
Fracție ordinarăPutere a lui 2Fracție zecimalăEchivalent în baza 2
în tabelul din suport, prima linie apare ca „0.0”; valoarea corectă pentru 1/2 este 0.1(2).

Binar → octal și binar → hexazecimal: gruparea biților

Se împarte numărul binar în grupuri de câte 3 biți (octal) sau 4 biți (hexazecimal), pornind de la dreapta; dacă e nevoie, se completează la stânga cu zerouri. Fiecare grup se înlocuiește cu cifra corespunzătoare.

suportul de curs spune la conversia binar–octal „cifră hexazecimală echivalentă”; corect este cifră octală.

Conversia inversă (hexazecimal → binar) înlocuiește fiecare cifră cu grupul ei de 4 biți: 264E → 0010 0110 0100 1110.

3. Reprezentarea numerelor întregi și reale

Numerele se reprezintă folosind un număr fix de biți: 8, 16, 32, 64, 80 (multipli de 8, pentru că memoria e organizată pe octeți). Pentru un întreg, cifra cea mai din stânga este cea mai semnificativă (MSB), iar cea din dreapta cea mai puțin semnificativă (LSB).

Domeniu de reprezentare și depășire

Cu n biți fără semn se pot reprezenta valorile din [0, 2n−1]. Dacă rezultatul nu încape, apare depășirea (overflow): biții cei mai semnificativi se pierd.

ndomeniu fără semn
8 biți0 – 255
16 biți0 – 65 535
32 biți0 – 4 294 967 295
suportul indică pentru 32 de biți domeniul 0 – 2 147 483 647; acela este maximul pentru întregi cu semn (231−1). Pentru întregi fără semn pe 32 de biți maximul este 232−1 = 4 294 967 295.

🧪 Sumator pe 8 biți: vezi depășirea

Numere cu semn: codul complementar față de 2

Cea mai uzuală reprezentare a numerelor cu semn. Avantaj: aceleași circuite din unitatea aritmetico-logică fac operațiile, indiferent dacă numerele sunt cu sau fără semn; diferă doar interpretarea biților.

Regula: complementul față de 2 se obține inversând toți biții și adunând 1. Cu n biți se reprezintă intervalul [−2n−1, 2n−1−1]. Bitul cel mai din stânga este bitul de semn (0 = pozitiv, 1 = negativ).

Roata codului complementar (4 biți)

Trece cu mouse-ul peste roată. Adunarea înseamnă rotire în sens orar; trecerea de la 0111 (7) la 1000 (−8) este depășirea cu semn.

Observații

  1. Bitul de semn nu se modifică la complementare dacă pornești de la reprezentarea „semn + mărime” (ca în curs).
  2. Valoarea fără semn a unui număr negativ x pe n biți: C2(x) = 2n − |x|. Ex.: −72 pe 8 biți → 256 − 72 = 184 = 10111000(2).
  3. x + (−x) = 0: 01001000 + 10111000 = (1)00000000.
  4. Și la numerele cu semn poate apărea depășirea: −100 − 30 = −130 < −128 ⇒ rezultat pozitiv incorect (01111110 = 126).

Virgulă fixă și virgulă mobilă

Virgulă fixă

Utilă când numerele din calcule au un număr total de cifre aproximativ egal; punctul zecimal este fixat între două cifre.

Virgulă mobilă

Utilă când numerele au ordine de mărime foarte diferite, ex. 9945000000 și 0.00023. Se bazează pe notația științifică.
a = ± m × 10E, 1 ≤ m < 10    →    în calculator: a = ± m × 2E, 1 ≤ m < 2, m = (1.b1b2b3…)(2)

Ex.: 264.39 = 2.6439 × 102; 0.00026439 = 2.6439 × 10−4; 9/2 = 100.1(2) = 1.001(2) × 22 (formă normalizată, unică dacă 1 ≤ m < 2).

Standardul IEEE 754

Simplă precizie (32 biți)
1 bit semn · 8 biți exponent (exces 127) · 23 biți mantisă
Dublă precizie (64 biți)
1 bit semn · 11 biți exponent (exces 1023) · 52 biți mantisă
caracteristica = exponent + 2(nr. biți exponent − 1) − 1

4. Coduri pentru reprezentarea datelor

Codurile se clasifică în coduri numerice (reprezintă datele numerice) și coduri alfanumerice (ASCII, EBCDIC, Unicode).

a) Coduri numerice ponderate și neponderate

În codurile ponderate fiecare cifră zecimală are un cod de 4 biți, iar fiecare poziție are o pondere: N = Σ ai·wi. În codurile neponderate biților nu li se asociază ponderi.

🔢 Convertor de coduri

Treci cu mouse-ul peste o coloană din tabel: bitul modificat față de cifra precedentă se evidențiază; la codul Gray se schimbă mereu un singur bit.

🔄 Codul Gray: numărător animat

Secvența e circulară (00 → 01 → 11 → 10 → 00). Compară câți biți se schimbă la fiecare pas în binar și în Gray.

Binar
Gray
// binar -> Gray                 // Gray -> binar
g[1] = b[1];                     b[1] = valoare = g[1];
for (i = 2; i <= m; i++)         for (i = 2; i <= m; i++) {
    g[i] = b[i-1] ^ b[i];            if (g[i] == 1) valoare = !valoare;
                                     b[i] = valoare;
                                 }

Coduri detectoare și corectoare de erori

Pe lângă cei n biți de date se adaugă k biți de control; vectorul de k+n biți formează un cuvânt de cod.

Bit de paritate

Se adaugă un bit astfel încât numărul de 1 să fie par (sau impar). Apasă pe un bit de date pentru a simula o eroare de transmisie.

Distanța Hamming

Numărul pozițiilor în care două cuvinte diferă.

Un cod cu distanța minimă Dmin detectează Dmin−1 erori și corectează ⌊(Dmin−1)/2⌋ erori.

Codul Hamming (7,4)

Pentru 4 biți de date se adaugă 3 biți de paritate pară, pe pozițiile puterilor lui 2: D7 D6 D5 P4 D3 P2 P1.

  • P1 – paritate pară pentru biții 1, 3, 5, 7
  • P2 – paritate pară pentru biții 2, 3, 6, 7
  • P4 – paritate pară pentru biții 4, 5, 6, 7

📡 Simulator de canal: detectează și corectează

Cuvântul recepționat: apasă pe un bit ca să introduci o eroare. Receptorul recalculează paritățile; numărul format de biții de control (P4 P2 P1) dă poziția bitului greșit.

Coduri polinomiale CRC

Un șir de biți se asociază unui polinom: 101011 → p(x) = x5 ⊕ x3 ⊕ x ⊕ 1. Aritmetica este modulo 2 (XOR). Receptorul împarte polinomul recepționat la polinomul generator; dacă restul este 0, transmisia a fost corectă.

Exemplul de împărțire CRC este o ilustrare suplimentară; suportul de curs prezintă doar principiul.

b) Coduri alfanumerice

ASCII – cod de 7 biți (27 = 128 caractere); ASCII extins – 8 biți (256 caractere; primele 128 identice). Codul unui caracter: grupul de 3 biți (coloana) pe pozițiile cele mai semnificative, urmat de grupul de 4 biți (linia). Apasă pe o celulă:

Ex.: a = 1100001 → 97 · A = 1000001 → 65 · z = 1111010 → 122

⌨️ Text → ASCII, în timp ce scrii

Al 8-lea bit din ASCII-8 poate fi: bit de paritate, întotdeauna 0, sau bitul care extinde setul la 256 de caractere.

EBCDIC

Cod de 8 biți (256 caractere), două grupuri de 4 biți: zona (categoria) și digit. Zona: cifre 1111, A–I 1100, J–R 1101, S–Z 1110.

Hollerith

Folosit până în anii ’80 pentru cartele perforate: 12 rânduri × 80 coloane; o gaură = o cifră, două găuri = o literă.

UNICODE

Cod pe 16 biți (65 536 caractere) cu un număr unic pentru fiecare caracter, indiferent de platformă sau limbă. ASCII este un subset al Unicode.

Rezumat

  • Calculatoarele prelucrează informația în binar; octalul și hexazecimalul comprimă șirurile lungi de biți.
  • Sistemele de numerație sunt poziționale; conversiile se fac din zecimal în baza r (împărțiri/înmulțiri succesive) și din baza r în zecimal (sumă ponderată).
  • Numerele se reprezintă pe un număr fix de biți (8, 16, 32, 64, 80); cu n biți fără semn domeniul este [0, 2n−1]; altfel apare depășirea.
  • Numerele cu semn se reprezintă în cod complementar față de 2 (inversare + 1).
  • Numerele reale: virgulă fixă sau virgulă mobilă (IEEE 754: simplă precizie 32 biți, dublă 64 biți).
  • Coduri numerice (BCD, 2-4-2-1, XS-3, Gray, paritate, Hamming, CRC) și alfanumerice (ASCII, EBCDIC, Unicode).

Laborator: reprezentarea datelor în C

Programele de mai jos ilustrează în limbajul C noțiunile din curs. Le poți copia și compila (gcc prog.c -o prog). Pentru fiecare program există un simulator care reproduce în pagină ieșirea programului pentru datele introduse de tine.

L1. Conversia unui întreg în baza b (împărțiri succesive)

#include <stdio.h>

int main(void) {
    unsigned int n, b;
    char cifre[] = "0123456789ABCDEF", rez[64];
    int k = 0;
    printf("n = "); scanf("%u", &n);
    printf("baza (2..16) = "); scanf("%u", &b);
    unsigned int x = n;
    do {                       /* resturile dau cifrele, de la LSB la MSB */
        rez[k++] = cifre[x % b];
        x = x / b;
    } while (x != 0);
    printf("%u(10) = ", n);
    while (k > 0) putchar(rez[--k]);   /* afisare in ordine inversa */
    printf("(%u)\n", b);
    printf("Verificare: octal %o, hex %X\n", n, n);
    return 0;
}

L2. Afișarea biților și complementul față de 2

#include <stdio.h>

void afis_biti(unsigned char v) {
    for (int i = 7; i >= 0; i--)
        putchar((v >> i) & 1 ? '1' : '0');   /* deplasare + masca */
}

int main(void) {
    signed char x;
    int t;
    printf("x (-128..127) = "); scanf("%d", &t);
    x = (signed char)t;
    printf("x      = %4d  -> ", x); afis_biti((unsigned char)x);  putchar('\n');
    printf("~x     = %4d  -> ", (signed char)~x); afis_biti((unsigned char)~x); putchar('\n');
    printf("~x + 1 = %4d  -> ", (signed char)(~x + 1)); afis_biti((unsigned char)(~x + 1)); putchar('\n');
    printf("fara semn: %u\n", (unsigned char)x);   /* 2^8 - |x| pentru x < 0 */

    unsigned char a = 64, b = 250, s = a + b;      /* depasire pe 8 biti */
    printf("64 + 250 pe 8 biti = %u\n", s);
    return 0;
}

L3. Cum arată un float în memorie (IEEE 754)

#include <stdio.h>
#include <string.h>
#include <stdint.h>

int main(void) {
    float f;
    uint32_t u;
    printf("f = "); scanf("%f", &f);
    memcpy(&u, &f, sizeof u);              /* copiem cei 32 de biti */
    unsigned s = u >> 31;
    unsigned e = (u >> 23) & 0xFF;         /* caracteristica (exces 127) */
    unsigned m = u & 0x7FFFFF;             /* 23 biti de mantisa */
    printf("hex: %08X\n", u);
    printf("semn = %u, caracteristica = %u, exponent = %d\n", s, e, (int)e - 127);
    printf("mantisa = 0x%06X\n", m);
    return 0;
}

L4. Codificarea Hamming (7,4) cu operații pe biți

#include <stdio.h>

/* pozitiile 1..7 : P1 P2 D3 P4 D5 D6 D7 */
int main(void) {
    int d[4], c[8] = {0};
    printf("4 biti de date (D7 D6 D5 D3): ");
    scanf("%1d%1d%1d%1d", &d[0], &d[1], &d[2], &d[3]);
    c[7] = d[0]; c[6] = d[1]; c[5] = d[2]; c[3] = d[3];
    c[1] = c[3] ^ c[5] ^ c[7];          /* paritate para */
    c[2] = c[3] ^ c[6] ^ c[7];
    c[4] = c[5] ^ c[6] ^ c[7];
    printf("Cod Hamming: ");
    for (int i = 7; i >= 1; i--) printf("%d", c[i]);
    printf("\n");
    return 0;
}

L5. Caractere și coduri ASCII

#include <stdio.h>

int main(void) {
    char s[100];
    printf("text: "); scanf("%99s", s);
    for (int i = 0; s[i] != '\0'; i++)

    printf("'a' - 'A' = %d\n", 'a' - 'A');   /* diferenta litere mici/mari */

}
